# Shadow

A shadow shows what sits above the page. The more an element covers, the stronger its shadow. Use a shadow token instead of a fixed value.

```jsx
import { shadowFloating } from '@bigbluebutton/bbb-ui-components-react';

const Menu = styled.div`
  box-shadow: ${shadowFloating};
`;
```

- Use one shadow per surface. The strongest belongs to the element on top.
- Don't put a shadow on an element that is part of the page, such as a card in a list.
- Don't make a shadow stronger on a dark background, where it is barely visible. Let the contrast of the surface separate it, with a border if needed.

A host page can change the color of a shadow, but not its size. The components do not all use these tokens yet.
