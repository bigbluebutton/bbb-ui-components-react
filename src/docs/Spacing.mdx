# Spacing

Use a spacing token for the space around and between elements, instead of a fixed value.

```jsx
import { spacingMedium } from '@bigbluebutton/bbb-ui-components-react';

const Card = styled.div`
  padding: ${spacingMedium};
`;
```

## How spacing works

1. **The scale** is one set of sizes, as tokens. Spacing has no semantic or component tokens, as color has.
2. **The rules** give each size its role: the padding inside an element, and the gap between two.

In this panel, the more closely two parts are related, the smaller the gap between them.

<SpacingExample padding="spacingLarge" steps={[
  { part: 'Section title', gap: 'spacingSmallMedium' },
  { part: 'Option', gap: 'spacingSmall' },
  { part: 'Another option', gap: 'spacingLarge' },
  { part: 'Next section title' },
]} />

Choose a size by where it goes, not by how it looks:

- **Space inside an element:** see [Padding](#padding).
- **Space between elements:** see [Gaps](#gaps).
- **Nothing there fits:** use `spacingMedium`. When two sizes fit, prefer a multiple of 8px.

## Padding

Use these for what you build yourself. The library's components set their own padding, so don't change it.

  { use: 'Tooltip', vertical: 'spacingXSmall', sides: 'spacingSmall' },
  { use: 'Badge', vertical: 'spacing0', sides: 'spacingSmallMedium' },
]} />

The larger the surface, the larger its padding. Use the same padding on all sides unless the element is listed above with different ones, and the same padding every time an element is repeated.

## Gaps

The gap shows how closely things are related: the less related, the larger the gap. Don't use one gap for items and for the groups they belong to, because people can no longer see the groups.

## Theming

Unlike colors, a host page cannot override spacing. Pixel values assume the browser's default text size.
