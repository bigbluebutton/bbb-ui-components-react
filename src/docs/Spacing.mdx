# Spacing

Use a spacing token for the space around and between elements, instead of a fixed value.

```jsx
import { spacingMedium } from '@bigbluebutton/bbb-ui-components-react';

const Card = styled.div`
  padding: ${spacingMedium};
`;
```

Unlike colors, a host page cannot override spacing. Pixel values assume the browser's default text size.
