# Radius

Use a radius token to round the corners of an element, instead of a fixed value.

```jsx
import { borderRadiusSmall } from '@bigbluebutton/bbb-ui-components-react';

const Card = styled.div`
  border-radius: ${borderRadiusSmall};
`;
```

Unlike colors, a host page cannot override the radius. Pixel values assume the browser's default text size.

## Choose a radius

The larger the surface, the larger its radius.

- **Up to about 40px tall:** `borderRadiusSmall`, or `borderRadiusFull` if it is circular.
- **About 40 to 600px:** `borderRadiusDefault`.
- **A large container where `borderRadiusDefault` feels small:** `borderRadiusLarge`.
- **As tall as the screen:** `borderRadiusXLarge`.
- **One element inside another:** the inner radius is the outer one minus the padding between them. For example, a menu with `borderRadiusSmall` has items with `borderRadiusNone`.
- **A ring around an element:** the radius of the element plus the thickness of the ring.

Don't use values outside the scale, such as 4, 10 or 12px, or a radius meant for a larger surface.

Some components do not follow these rules yet.
