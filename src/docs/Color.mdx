# Color

Use a color token instead of a fixed value, so that a change to the token, or a host page's theme, reaches every screen.

```jsx
import { colors } from '@bigbluebutton/bbb-ui-components-react/colors';

const Card = styled.div`
  color: ${colors.text.default};
  background: ${colors.background.white};
`;
```

## How color works

Colors come in three layers, and a color points to one in an earlier layer.

1. **Primitives** are the values, such as a blue. They have no role, and are not exported.
2. **Semantic colors** give a value a role, such as main actions. These are the colors to use.
3. **Component colors** give one part of the app its own color, such as the sidebar.

In this example, a change to the semantic color also changes the component color.

{/* BEGIN chain: generated from tokens/tokens.json by npm run tokens. Do not edit. */}

<ColorChain steps={[
  { name: 'palette.blue.500', value: '#0F70D7', purpose: '' },
  { name: 'colors.brand.brand1', value: '#0F70D7', purpose: 'Main actions, links and highlighted text.' },
  { name: 'colors.whiteboard.selected', value: '#0F70D7', purpose: 'Selected item in the whiteboard.' },
]} />

{/* END chain */}

Choose a color by what it is for, not by how it looks:

- Start with a semantic color.
- Use a component color only for the part of the app it is named after.
- Never use a primitive, or copy its value.

Some semantic colors reach their primitive through one of the colors kept for existing apps, such as `colors.neutral.neutral3`. Use the semantic color, not the one in between.

## Semantic colors

What are you coloring?

- **Text:** see [Text](#text).
- **An icon:** see [Icon](#icon).
- **A page, panel, field or other area, or its hover:** see [Background](#background).
- **An outline or a divider:** see [Border](#border).
- **A button or other control that does something:** see [Action](#action).
- **A message or status, such as success or an error:** see [Feedback](#feedback).
- **A shadow:** see [Shadow](#shadow). For a complete shadow, use a token from the Shadow page.

The lists are by role, so a color with two roles is in both, and a name can start with another word than its list. Import a name that starts with `colors.` from the `colors` object, and any other by itself from `@bigbluebutton/bbb-ui-components-react`.

## Theming

To change a color in a host page, set one of its CSS variables. The first one that is set wins, and the default value applies when none is. A color that points to another follows it, unless its own variable is set.

The samples in the semantic and component lists show the colors in use now. The primitives always show their fixed value.

The library has no dark values. The BigBlueButton client sets its own.
