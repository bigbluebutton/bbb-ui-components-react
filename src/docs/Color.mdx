# Color

Use a color token instead of a fixed value, so that a change to the token, or a host page's theme, reaches every screen.

```jsx
import { colors } from '@bigbluebutton/bbb-ui-components-react/colors';

const Card = styled.div`
  color: ${colors.text.default};
  background: ${colors.background.white};
`;
```

To change a color in a host page, set one of its CSS variables. The samples below show the colors in use now. The default value applies when none of the variables is set.
