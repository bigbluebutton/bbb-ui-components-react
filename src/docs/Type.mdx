# Type

Use these tokens inside the library to size and weigh text. They are not exported from the package. In a product screen, use [BBBTypography](?path=/docs/bbbtypography--docs), which applies them for you. Pixel values assume the browser's default text size.

## Text styles in Figma

A style sets the size and weight together. Use the BBBTypography variant where there is one, and don't adjust its size or weight.

- **Heading/Panel:** 16px, bold, uppercase. Panel and modal headers. BBBTypography `header`.
- **Heading/Section:** 16px, semibold. Groups inside panels and modals. No variant yet.
- **Body/Default:** 16px, regular. Default text, list and navigation items. BBBTypography `default`.
- **Body/Selected:** 16px, bold. Active items and card titles. BBBTypography `selected`.
- **Body/Text 2:** 14px, regular, secondary text color. Labels, descriptions and chat messages. BBBTypography `text2`.
- **Body/Text 3:** 12px, regular, secondary text color. Times and marks. BBBTypography `text3`.
- **Label/Button:** 16px, semibold. Buttons and tabs. BBBTypography `button`.
- **Label/Small:** 12px, semibold. Names on video tiles, small badges and counters. No variant yet.
- **Heading/Display:** 32px, semibold. Timers and durations, numbers only. Live only, no variant.
- **Heading/Highlight:** 24px, bold. Empty states and highlight titles, one per screen. Live only, no variant.
- **Body/Large:** 20px, regular. Large menus and captions over video. Live only, no variant.

The line height is automatic. When in doubt, start with Body/Default.
