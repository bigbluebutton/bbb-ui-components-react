# Type

Use [BBBTypography](?path=/docs/bbbtypography--docs) for text, instead of setting its size and weight.

```jsx
import { BBBTypography } from '@bigbluebutton/bbb-ui-components-react';

<BBBTypography variant="header">Participants</BBBTypography>
```

## How type works

1. **Tokens** are single values: a family, a size or a weight. They are for code inside the library, and are not exported.
2. **Text styles** combine a size and a weight, and give them a role, such as panel titles.
3. **Components** apply a style for you. BBBTypography has a variant for each style it supports, and other components, such as BBButton, style their own text.

In this example, two tokens make the style for panel titles.

<TypeChain tokens={['fontSizeDefault', 'fontWeightHard']} style="Heading/Panel, in uppercase" variant="header" />

Choose a style by what the text is for, not by its size:

- Start with the `default` variant.
- Use a variant as it is. Don't adjust its size or weight.
- Never use a token, or copy its value, in a product screen.

## Theming

A host page sets the font, and cannot override sizes or weights. Pixel values assume the browser's default text size.
