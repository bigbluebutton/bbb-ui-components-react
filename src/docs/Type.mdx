# Type

Use [BBBTypography](?path=/docs/bbbtypography--docs) for text, instead of setting a size and weight. Use a text style where you cannot use the component.

```jsx
import { BBBTypography } from '@bigbluebutton/bbb-ui-components-react';

<BBBTypography variant="header">Participants</BBBTypography>
```

```jsx
import { colors, textStyles } from '@bigbluebutton/bbb-ui-components-react';

const Field = styled.input`
  ${textStyles.body.default}
  color: ${colors.text.default};
`;
```

## How type works

1. **Tokens** are single values: a family, a size or a weight. They are for code inside the library, and are not exported.
2. **Text styles** are tokens that combine a size and a weight, and give them a role, such as panel titles. They are exported as `textStyles`.
3. **Components** apply a style for you. BBBTypography has a variant for each style, and other components, such as BBButton, style their own text.

In this example, two tokens make the style for panel titles.

<TypeChain tokens={['fontSizeDefault', 'fontWeightHard']} style="textStyles.heading.panel" variant="header" />

Choose a style by what the text is for, not by its size:

- Start with the `default` variant of BBBTypography.
- Where you cannot use BBBTypography, such as in the styles of another element, use `textStyles`.
- Use a style as it is. Don't adjust its size or weight.
- Never use a size or weight token, or copy its value, in a product screen.

The components do not set the font. They take it from the app, except BBBTextInput and BBBSelect. Buttons and most fields take it only when the app's styles make form controls inherit the font, as in the BigBlueButton client and in Storybook.

Storybook loads Nunito Sans, as in Figma. The client uses Source Sans Pro and does not load Nunito Sans, so don't set `fontFamily` there: let the app's font apply.

## Theming

A host page sets the font, and cannot override sizes or weights. Pixel values assume the browser's default text size.
