# BBBSpinner guidelines

## When to use

Use BBBSpinner while something is loading or being processed and there is no way to show how far along it is.

Use something else when:

- The result is ready or has failed: use BBBToast, or show a message in place.
- A button needs to confirm a click: use the click feedback of BBButton.
- A search is loading: BBBSearch has its own loading state.

## Structure

A single part: an arc that rotates, in the brand color. It has no label.

<Canvas of={Stories.Default} />

## Choose a spinner

- **Size:** keep the default for a page or panel that is loading, and use a smaller one next to text or a button.
- **Label:** add visible text next to it when the wait is long or the reason is not clear.
- **Place:** put it where the result will appear, and remove it when the work ends.

## Accessibility

- It is exposed as a progress bar named "Loading", with no value.
- Known gap: the name is always in English and cannot be translated.
- Known gap: the animation does not follow the person's reduced motion setting. Set `animate={false}` in the app when that setting is on.
